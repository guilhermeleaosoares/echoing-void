# Antigravity brief — void food art, and two new animals

You have **full thematic, 3D and texture creative direction** on everything in
this document. What follows is the mechanical skeleton only: names, file paths,
sizes, and the gameplay each thing has to read as. The look is yours.

Project rules that are not yours to change:

- Every texture in this mod is **generated by a Python tool in `tools/`**, never
  hand-painted into `src/`. A hand-edited PNG gets silently overwritten the next
  time anyone runs `python tools/asset_gen.py` — that has already happened once
  here and cost a day. Put your work in the generator that owns the file.
- `python tools/verify_textures.py` is a hard gate: 16x16 for items, 5-16
  distinct colours, dark outline, on-palette against
  `docs/spec/art_direction.json`. Run it. If a colour you want is off-palette,
  the palette file is the thing to extend, deliberately, not the check to skip.
- `python tools/verify_models.py` audits creature geometry: valid bones,
  resolvable parents, in-bounds non-overlapping UVs.
- Creature geometry has a single source of truth:
  `assets/echoing_void/geo/*.geo.json`, converted into Java `LayerDefinition`
  classes by `tools/gen_entity_models.py`. Edit the geo, re-run the generator.
  Do not hand-write the Java.

## Part 1 — the two new animals

The Hollow Horizon has no livestock. These are its cow and its pig: **passive,
killable, drop meat**. I am writing all the AI, spawning, loot and registration.
You are designing what they *are*.

| | cow equivalent | pig equivalent |
|---|---|---|
| entity id | `echoing_void:drone_auroch` | `echoing_void:thrum_boar` |
| raw meat | `echoing_void:drone_loin` | `echoing_void:thrum_ribs` |
| cooked meat | `echoing_void:seared_drone_loin` | `echoing_void:seared_thrum_ribs` |

Names are fixed (the player chose the "loin" and "ribs" shape). Everything about
their bodies, silhouettes, palettes and animation character is open.

The one thing that must come through: this is a **resonance and acoustics**
dimension. Its creatures are not flesh-and-bone animals that wandered in — the
Echo Weaver, Strata Golem, Resonance Wraith and Chime Mote already establish
that. A "drone" is a sustained low note; a "thrum" is a rhythmic hum. Those are
the words the player picked, and the animals should look like the sound they are
named after. Look at the existing three geo files before you start so these read
as the same ecosystem.

Deliverables per animal:

- `assets/echoing_void/geo/<id>.geo.json` — the body
- `assets/echoing_void/textures/entity/<id>.png` — the skin
- the four meat item icons above, 16x16
- an offline render of each so the player can look at it before it ships
  (`tools/render_geo_preview.py` does this for the existing creatures)

## Part 2 — new food icons

- `textures/item/echo_gourd_slice.png` — the Echo Gourd cut into slices, the way
  a melon slice reads next to a melon. It has to be recognisably a piece of the
  gourd block whose textures already exist.
- `textures/item/humming_tart.png` — this dimension's pumpkin pie. Baked, edible,
  and it should look like it hums. It is the best food in the mod and should
  look like the reward it is.

improves everything it touches is not a review.

## Verifying your own work

Measure, do not eyeball, and do not report success from a summary: render the
sprite, open it, and compare it against the vanilla item it sits beside in the
inventory. This project has been burned by "done" claims that a `git diff` did
not support.
